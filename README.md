# TexTage 皿の押し引き

TexTageのIIDX譜面上で、スクラッチ（皿）の押し引きや連皿の枚数を確認できる非公式の補助ツールです。SP・DPに対応しています。

## スクリプトの取得

**[取得ページを開く](https://aki0311-commits.github.io/Scratch/)**

取得ページにあるボタンから、iPhone・Androidそれぞれのブックマーク用コードをコピーできます。ページ内の模擬譜面でも操作を試せます。

## 主な機能

- **赤＝押し、青＝引き**で皿を交互に色分け
- 連皿の押し引き方向を矢印で表示
- 連皿の枚数や、変速皿の種類を表示
- 1P／2P切り替え、DPの左右皿に対応
- 色や矢印の編集、戻す・進む・リセット
- BSS・MSSの切り返しにも対応
- **皿餡蜜（試験機能）**で、24分・32分皿を早入りさせ、16分に近い間隔を表示

皿餡蜜の早入りは最大116.7msです。110ms超の早入りは橙枠で示します。この数値は実機でGOOD判定になることを保証するものではありません。

## 使い方

### iPhone（Safari）

1. [取得ページ](https://aki0311-commits.github.io/Scratch/)で「ブックマーク用コードをコピー」を押します。
2. Safariでページをブックマークに追加します。
3. ブックマーク一覧で追加した項目を長押しして「編集」を選び、URLをコピーしたコードに置き換えて保存します。
4. [TexTage](https://textage.cc/score/index.html)で譜面を開き、保存したブックマークを押すと起動します。

### Android（Chrome）

1. [取得ページ](https://aki0311-commits.github.io/Scratch/)で「Android用の短いコードをコピー」を押します。
2. ページをブックマークに追加し、ブックマークの編集画面でURLをコピーしたコードに置き換えて保存します。
3. TexTageで譜面を開き、アドレスバーにブックマーク名を入力して候補から選ぶと起動します。

Android用の短いコードは起動時に取得ページへ接続します。

## 操作のヒント

- 「枚数」で連皿の枚数表示を切り替えられます。
- 「変速皿」で12分・24分・32分の皿を色分けできます。
- 連皿の先頭をタップすると色を反転できます。矢印や色は画面上で編集できます。
- 「隠す」で操作パネルを小さくでき、再表示も可能です。
- MIRRORなどで譜面の表示を変えた場合は、いったん「終了」してから起動し直してください。

譜面の特殊な構成によって、表示位置がずれる場合があります。「終了」で元の表示に戻り、譜面データ自体は変更・送信しません。

## ファイル構成

- `src/bookmarklet.js`：スクリプトの編集用ソース
- `docs/index.html`：取得・使い方ページ
- `docs/b.js`：Android用の短いコードから読み込むスクリプト
- `docs/*.gif`：模擬譜面用画像

ソース編集後は `python3 scripts/build.py` で公開用ファイルを更新できます。
